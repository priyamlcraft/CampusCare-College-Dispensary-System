# Frontend – CampusCare

The frontend of CampusCare is developed using React.js and Vite. It provides a user-friendly interface for the College Dispensary Management System.

## Technologies Used
- React.js
- Vite
- HTML5
- CSS3
- JavaScript

## Features
- Interactive user interface
- Component-based architecture
- API integration with backend
- User-friendly navigation

## Installation

```bash
npm install
```

## Run the Application

```bash
npm run dev
```

## Production Build

```bash
npm run build
```

## Dependencies

All frontend dependencies are listed in `package.json` and `package-lock.json`.
